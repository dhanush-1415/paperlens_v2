# PaperLens v2.1 Missing Features Audit (Scan & Integrations)

After completing the Document Analysis core features, here is the follow-up audit checklist of the remaining legacy capabilities from `clearcut-app` that are currently missing in the `paperlens-v2.1` architecture:

## 1. Upload & Scan Interface
- [x] **Scanner Camera (`scanner-camera.tsx`):** Integrate the legacy mobile camera scanner into the new `OmniDropzone` to allow users to capture, crop, and upload physical documents directly from their mobile devices.
- [x] **Email-to-Vault Inbox (`inbox-address.tsx`):** Implement the dedicated email alias feature (`username@inbox.paperlens.app`), allowing users to forward email attachments directly to their PaperLens Vault for automated background scanning.

## 2. Advanced Document Integrations
- [x] **Expert Escalation (`expert-escalation.tsx`):** Add the lawyer connection/escalation UI prompt. This should trigger when the AI analyzes a document and returns a "Critical" risk score, offering the user a direct pathway to legal counsel.
- [x] **Sync Action Plan (`sync-plan-button.tsx`):** Implement the external integration buttons (Notion, Jira) for the Smart Action Plan, allowing users to export their checklist tasks out of the document report.

## 3. Compliance & Marketing (Optional)
- [x] **Cookie Consent Banner (`cookie-banner.tsx` & `cookie-settings-button.tsx`):** Migrate the legacy GDPR cookie consent banners to the v2.1 application shell.
- [x] **Marketing & Lead Gen:** Review whether `blog-newsletter-cta.tsx`, `email-capture.tsx`, and the `faq-accordion.tsx` need to be migrated to the v2.1 marketing routes.
